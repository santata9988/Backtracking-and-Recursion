บทที่ 7

วิธีย้อนกลับ (Backtracking)

เทคนิคออกแบบอัลกอริทึมสำหรับปัญหาค้นหาคำตอบจากความเป็นไปได้จำนวนมาก สร้างคำตอบทีละขั้น ตรวจทุกขั้น และย้อนกลับเมื่อเจอทางตัน

7.1หลักการทำงาน

  1. เริ่มจากสถานะว่าง (empty state)
  2. เลือกหนึ่งทางเลือก แล้วเพิ่มเข้าไปในคำตอบบางส่วน (partial solution)
  3. ตรวจเงื่อนไข: ถ้าสอดคล้องให้เดินหน้าต่อ ถ้าไม่สอดคล้องให้ย้อนกลับแล้วเลือกทางอื่น
  4. ทำซ้ำจนได้คำตอบทั้งหมดหรือคำตอบที่ดีที่สุด

7.2คุณสมบัติสำคัญ

คุณสมบัติคำอธิบายตัวอย่าง
สร้างคำตอบทีละขั้นเริ่มจากว่างแล้วเพิ่มองค์ประกอบทีละส่วน และตรวจว่ายังไปถึงคำตอบสมบูรณ์ได้หรือไม่วาง Queen บนกระดานทีละตัว
ย้อนกลับ (Backtrack)ถ้าเส้นทางไม่ถูกต้องให้ undo แล้วลองทางอื่น เป็นการลองผิดลองถูกอย่างมีระบบเจอทางตันในเขาวงกต
ตัดกิ่ง (Pruning)ใช้เงื่อนไขตัดทางเลือกที่เป็นไปไม่ได้ทิ้งทันที ลดจำนวนการค้นหาSudoku: เลขซ้ำในแถวหรือคอลัมน์
ทำงานแบบ Recursiveแต่ละการเรียกทำหน้าที่ เลือก → ตรวจ → เดินหน้า → ย้อนกลับฟังก์ชันแก้ N-Queens
ความสมบูรณ์ (Completeness)ถ้าไม่ตัดกิ่งจะได้คำตอบทุกแบบ และถ้าตัดกิ่งถูกต้องคำตอบที่เหลือก็ยังถูกต้องN-Queens หาได้ครบทุกแบบ
ความซับซ้อนเชิงเวลาทั่วไปเป็น exponential เช่น O(2ⁿ), O(n!) แต่ pruning ทำให้เร็วกว่าที่วิเคราะห์ในทางทฤษฎีSudoku
ความเหมาะสมของปัญหาปัญหา combinatorial และ search ที่ใช้ Greedy หรือ DP ได้ยากGraph Coloring, Knight's Tour
ความยืดหยุ่นหาคำตอบเดียว คำตอบทั้งหมด หรือคำตอบที่ดีที่สุดก็ได้Sudoku

7.3ปัญหา N-Queens

วาง Queen จำนวน N ตัวบนกระดาน N×N โดยไม่ให้ตัวใดโจมตีตัวอื่นได้ Queen โจมตีได้ 3 ทิศทาง คือแนวนอน แนวตั้ง และแนวทแยงทั้งสองทิศ จึงห้ามมี Queen สองตัวอยู่แถวเดียวกัน คอลัมน์เดียวกัน หรือแนวทแยงเดียวกัน

กรณีเล็ก

  • N = 1 วางได้ 1 วิธี
  • N = 2 หรือ 3 ไม่มีคำตอบ
  • N = 4 วางได้ 2 วิธี

แนวคิดการแก้

  • วางทีละแถว เริ่มจากแถวแรก
  • ตรวจว่าไม่ขัดกับ Queen ที่วางไปแล้ว
  • ถ้าแถวไหนวางไม่ได้เลย ย้อนกลับไปแถวก่อนหน้าแล้วลองคอลัมน์อื่น
  • ทำซ้ำจนครบ N ตัว

ลองรัน N-Queens

โปรแกรม 7.1 · N-Queens (Python)
# Function to check if it is safe to place
# the queen at board[row][col]
def isSafe(mat, row, col):
    n = len(mat)

    # Check this col on upper side
    for i in range(row):
        if mat[i][col]:
            return False

    # Check upper diagonal on left side
    for i, j in zip(range(row - 1, -1, -1),
                    range(col - 1, -1, -1)):
        if mat[i][j]:
            return False

    # Check upper diagonal on right side
    for i, j in zip(range(row - 1, -1, -1),
                    range(col + 1, n)):
        if mat[i][j]:
            return False

    return True

def placeQueens(row, mat):
    n = len(mat)

    # If all queens are placed then return true
    if row == n:
        return True

    # Try placing queen in all columns one by one
    for i in range(n):
        if isSafe(mat, row, i):
            mat[row][i] = 1
            if placeQueens(row + 1, mat):
                return True
            mat[row][i] = 0      # backtrack

    return False

# Function to find the solution to the N-Queens problem
def nQueen(n):
    mat = [[0 for _ in range(n)] for _ in range(n)]

    if placeQueens(0, mat):
        ans = []                  # columns of the queens
        for i in range(n):
            for j in range(n):
                if mat[i][j]:
                    ans.append(j + 1)
        return ans
    else:
        return [-1]

if __name__ == "__main__":
    n = 4
    ans = nQueen(n)
    print(" ".join(map(str, ans)))

อธิบายแต่ละฟังก์ชัน

ฟังก์ชันหน้าที่กระบวนการ
isSafe(mat, row, col)ตรวจว่าวาง Queen ที่ (row, col) ปลอดภัยหรือไม่ตรวจคอลัมน์เดียวกันด้านบน แนวทแยงซ้ายบน และแนวทแยงขวาบน ถ้าเสี่ยงโดนโจมตีคืน False ถ้าปลอดภัยคืน True
placeQueens(row, mat)วาง Queen ทีละแถวด้วย Backtrackingถ้า row == n คืน True (พบคำตอบ) จากนั้นลองทุกคอลัมน์ ถ้า isSafe ให้วางแล้วเรียก placeQueens(row+1) ถ้าตันให้เอา Queen ออก (mat[row][i] = 0) ถ้าไม่มีคอลัมน์ใดวางได้คืน False
nQueen(n)เตรียมบอร์ดและเรียก placeQueensสร้างบอร์ด n×n ค่า 0 ทุกช่อง เรียก placeQueens(0, mat) ถ้ามีคำตอบคืนลิสต์คอลัมน์ (เลขคอลัมน์ + 1) ของแต่ละแถว ถ้าไม่มีคืน [-1]
__main__จุดเริ่มต้นโปรแกรมกำหนด n = 4 เรียก nQueen(n) และพิมพ์ตำแหน่งคอลัมน์ของ Queen แต่ละแถว

การวิเคราะห์ความซับซ้อน

เวลา: O(n·n!)

แต่ละแถวลองได้สูงสุด n คอลัมน์ ขอบเขตหยาบคือ nⁿ แต่เพราะห้ามซ้ำคอลัมน์ จึงเหลือเท่ากับ permutation ของคอลัมน์ คือ n! แต่ละการวางเรียก isSafe ที่ใช้ O(n) รวมเป็น O(n·n!)

พื้นที่: O(n²)

บอร์ด n×n ใช้ O(n²) และ stack ของ recursion ลึกสุด n ใช้ O(n) รวมเป็น O(n²)

7.4ปัญหาเดินเขาวงกต

หาทางจากจุดเริ่มต้น (S) ไปจุดสิ้นสุด (G) โดยเดินได้เฉพาะช่องที่เปิด (ค่า 1) และหลีกเลี่ยงกำแพง (ค่า 0) อัลกอริทึมเดินหน้าทีละก้าวในทุกทิศ ถ้าเจอทางตันก็ย้อนกลับมายังตำแหน่งก่อนหน้าเพื่อลองเส้นทางใหม่ จนพบทางออกหรือยืนยันว่าไม่มี

  1. เริ่มที่จุดเริ่มต้น เช่น (0,0)
  2. ตรวจเงื่อนไข: ถึงจุดหมายแล้วให้แสดงทางออกและจบ ถ้าออกนอกเขตหรือชนกำแพงให้ย้อนกลับ
  3. ทำเครื่องหมายตำแหน่งที่มาแล้ว เพื่อไม่ให้วนซ้ำ
  4. ลองเคลื่อนที่ทุกทิศ (ขวา ลง ซ้าย ขึ้น)
  5. ถ้าทางใดไปถึงจุดหมายได้ ส่งผลลัพธ์กลับ
  6. ถ้าไม่มีทิศใดไปต่อได้ ย้อนกลับหนึ่งขั้นแล้วลองเส้นทางใหม่

Pseudo-code

Algorithm SolveMaze(maze, x, y, solution):
    if (x, y) คือ จุดหมาย (Goal):
        แสดงเส้นทางใน solution
        return True

    if (x, y) เป็นตำแหน่งที่เดินได้และยังไม่เคยไป:
        ทำเครื่องหมาย solution[x][y] = 1

        if SolveMaze(maze, x + 1, y, solution): return True   # ขวา
        if SolveMaze(maze, x, y + 1, solution): return True   # ลง
        if SolveMaze(maze, x - 1, y, solution): return True   # ซ้าย
        if SolveMaze(maze, x, y - 1, solution): return True   # ขึ้น

        # หากไม่มีทางไป — ย้อนกลับ
        solution[x][y] = 0
        return False

    return False

โค้ด Python

Maze Solver using Backtracking
from typing import List, Tuple, Optional

# พิกัด (แถว, คอลัมน์)
Coord = Tuple[int, int]

# ค้นหาตำแหน่งเริ่มต้น (S) และเป้าหมาย (G)
def find_start_goal(maze: List[List[str]]) -> Tuple[Coord, Coord]:
    start = goal = None
    for r, row in enumerate(maze):
        for c, val in enumerate(row):
            if val == 'S':
                start = (r, c)
            elif val == 'G':
                goal = (r, c)
    if start is None or goal is None:
        raise ValueError("Maze must contain 'S' (start) and 'G' (goal).")
    return start, goal

# ตรวจว่าพิกัดอยู่ในขอบเขตหรือไม่
def in_bounds(maze: List[List[str]], r: int, c: int) -> bool:
    return 0 <= r < len(maze) and 0 <= c < len(maze[0])

# ตรวจว่าเดินได้หรือไม่ (1, S, G)
def is_open(maze: List[List[str]], r: int, c: int) -> bool:
    return maze[r][c] in ('1', 'S', 'G')

# ฟังก์ชันหลัก: Backtracking หาเส้นทาง S → G
def solve_maze_backtracking(maze: List[List[str]]) -> Optional[List[Coord]]:
    start, goal = find_start_goal(maze)
    visited = [[False]*len(maze[0]) for _ in range(len(maze))]
    path: List[Coord] = []

    # ทิศทาง: ขวา, ลง, ซ้าย, ขึ้น
    dirs = [(0,1), (1,0), (0,-1), (-1,0)]

    def dfs(r: int, c: int) -> bool:
        # นอกขอบเขต / เดินไม่ได้ / เคยมาแล้ว → กลับ
        if not in_bounds(maze, r, c) or not is_open(maze, r, c) or visited[r][c]:
            return False

        path.append((r, c))
        visited[r][c] = True

        if (r, c) == goal:        # ถึงเป้าหมาย
            return True

        for dr, dc in dirs:
            nr, nc = r + dr, c + dc
            if dfs(nr, nc):
                return True

        path.pop()                # ไม่มีทางไปต่อ → Backtrack
        return False

    found = dfs(*start)
    return path if found else None

# แสดงผลโดยใส่ "*" ลงในเส้นทางที่พบ
def render_solution(maze: List[List[str]], path: Optional[List[Coord]]) -> List[str]:
    view = [row[:] for row in maze]
    if path:
        for (r, c) in path:
            if view[r][c] not in ('S', 'G'):
                view[r][c] = '*'
    return [' '.join(row) for row in view]

def print_grid(grid_lines: List[str]) -> None:
    for line in grid_lines:
        print(line)

# เขาวงกตตัวอย่าง 4x4
def example_maze() -> List[List[str]]:
    return [
        ['S','1','0','0'],
        ['1','1','1','0'],
        ['0','1','0','0'],
        ['1','1','1','G'],
    ]

if __name__ == "__main__":
    maze = example_maze()
    path = solve_maze_backtracking(maze)

    print("Input Maze:")
    print_grid([' '.join(row) for row in maze])

    print("\nSolving...\n")
    if path is None:
        print("No path found.")
    else:
        print(f"Path found with {len(path)} steps:")
        print(path)
        print("\nSolution view ('*' marks the path):")
        print_grid(render_solution(maze, path))

ข้อสังเกตเมื่อเทียบกับตำราเล่มนี้: ผลลัพธ์ที่พิมพ์ในหนังสือแสดงพิกัด (1, 2) อยู่ในเส้นทางด้วย และแสดงแถวที่สองเป็น 0 * * 0 แต่ช่อง (1, 2) เป็นทางตัน โค้ดจะ path.pop() ออกตอน backtrack เมื่อรันจริงเส้นทางมี 7 ช่อง ไม่มี (1, 2) ตามที่แสดงข้างต้น

การวิเคราะห์ประสิทธิภาพ (ตามตำรา)

  • Best case: พบทางออกตั้งแต่เส้นทางแรก
  • Worst case: ต้องสำรวจทุกเส้นทาง (ตำราระบุว่าเป็นแบบ exponential เมื่อมี 4 ทิศในทุกช่อง)
  • Backtracking เป็น exponential algorithm แต่เหมาะกับการค้นหาคำตอบแบบสมบูรณ์ในปัญหาที่มีพื้นที่จำกัด เช่น เขาวงกต, Sudoku, N-Queens

7.6Backtracking เทียบกับ Brute Force

ประเด็นBrute ForceBacktracking
แนวคิดหลักลองทุกความเป็นไปได้แบบตรง ๆลองทีละขั้น ถ้าไม่เป็นไปตามเงื่อนไขให้ย้อนกลับ
การตัดกิ่งไม่มี ต้องตรวจทุกทางเลือกมี เพื่อลดจำนวนการค้นหา
จำนวนการค้นหาทุกความเป็นไปได้ สูงมากเฉพาะเส้นทางที่ยังเป็นไปได้ น้อยลง
ประสิทธิภาพช้ามากในปัญหา combinatorial ขนาดใหญ่เร็วกว่ามากถ้า pruning ดี แม้ยังเป็น exponential
การประยุกต์ใช้เป็น baseline หรือวิธีง่ายที่สุดปัญหา combinatorial ซับซ้อน เช่น N-Queens, Sudoku
ความสมบูรณ์ได้คำตอบครบทุกแบบแน่นอนได้ครบเช่นกัน แต่มีประสิทธิภาพมากกว่า
ตัวอย่างหา subset ทั้งหมดของเซตSudoku: เลือกตัวเลขทีละช่อง ย้อนกลับถ้าไม่ถูกต้อง

7.7ปัญหาที่แก้ด้วย Backtracking

ปัญหาคำอธิบายแนวทาง
N-Queensวาง N Queen บนกระดาน N×N โดยห้ามโจมตีกันวางทีละแถว ตรวจคอลัมน์และแนวทแยง ถ้าไม่ปลอดภัยให้ backtrack
Sudoku Solverเติมเลข 1–9 ในตาราง 9×9 ไม่ซ้ำแถว คอลัมน์ และบล็อกย่อยเติมทีละช่อง ตรวจเงื่อนไข ถ้าไม่ได้ให้ย้อนไปแก้ช่องก่อนหน้า
Graph Coloringระบายสีโหนดโดยห้ามโหนดติดกันสีเดียวกันกำหนดสีทีละโหนด ถ้าสีชนให้ย้อนกลับและลองสีอื่น
Hamiltonian Cycleหาเส้นทางปิดที่ผ่านทุกโหนดเพียงครั้งเดียวเลือกโหนดต่อไปทีละขั้น ตรวจว่าเส้นทางยัง valid
Knight's Tourเดินม้าบนกระดานให้ครบทุกช่องโดยไม่ซ้ำลองย้ายทีละตำแหน่ง ตรวจว่าเดินได้หรือไม่
Maze Solvingหาทางออกจากเขาวงกตเดินทีละก้าว เจอทางตันให้ย้อนกลับแล้วเลือกเส้นใหม่
Subset Sumหา subset ที่ผลรวมเท่าค่าที่กำหนดหรือไม่เลือกหรือไม่เลือกสมาชิกทีละตัว ถ้าผลรวมเกินเป้าให้ backtrack
Word Searchค้นหาคำในตารางตัวอักษรโดยอักษรต้องอยู่ติดกันเริ่มจากตัวแรก ขยายไปทุกทิศ ถ้าไม่ตรงคำให้ย้อนกลับ

7.10แบบฝึกหัดและเฉลย

1. แนวคิดหลักของ Backtracking เทียบกับ Brute Force
  • Backtracking: สร้างคำตอบทีละขั้น ถ้าคำตอบบางส่วนไปต่อไม่ได้ก็ย้อนกลับและลองทางใหม่ เป็นการลองผิดลองถูกแบบมีระบบ
  • Brute Force: ตรวจทุกความเป็นไปได้ (exhaustive search) โดยไม่ตัดกิ่ง
  • Brute Force ครอบคลุมทุกกรณีแต่ช้า ส่วน Backtracking เร็วกว่าด้วย pruning และยังได้คำตอบถูกต้องครบถ้วน
2. Pruning สำคัญอย่างไรใน Backtracking

Pruning คือการหยุดสำรวจเส้นทางที่ไม่มีทางถึงคำตอบตั้งแต่เนิ่น ๆ ช่วยลดจำนวนเส้นทางที่ต้องค้นหา ไม่เสียเวลากับเส้นทางที่เป็นไปไม่ได้ และทำให้แก้ปัญหาซับซ้อนอย่าง Sudoku หรือ N-Queens ได้

3. ตัวอย่างปัญหาที่แก้ด้วย Backtracking อย่างน้อย 3 ปัญหา
  • N-Queens: วางทีละแถว ตรวจว่าไม่ขัดกับ Queen ก่อนหน้า ถ้าไม่ได้ให้ backtrack
  • Sudoku Solver: เติมเลขทีละช่อง ตรวจว่าไม่ซ้ำแถว คอลัมน์ และบล็อก ถ้าซ้ำให้ย้อนกลับ
  • Maze Solving: เดินทีละก้าว ถ้าเจอทางตันให้ย้อนไปจุดก่อนหน้าแล้วเลือกทางใหม่
4. ความซับซ้อนเชิงเวลาของ N-Queens
  • การวางมีความเป็นไปได้สูงสุด n! วิธี (แต่ละแถววาง 1 คอลัมน์ที่ไม่ซ้ำกัน)
  • ทุกครั้งที่วางเรียก isSafe ใช้ O(n)
  • เวลารวม O(n·n!) และพื้นที่ O(n²)
5. ข้อดีและข้อจำกัดเมื่อเทียบกับ Dynamic Programming

ข้อดี: เข้าใจง่ายและยืดหยุ่น ใช้ได้กับหลายปัญหา combinatorial, หาคำตอบทั้งหมดได้ (ไม่ใช่แค่ค่าที่ดีที่สุด), ใช้ pruning ลดการค้นหา

ข้อจำกัด: เวลาโดยทั่วไปยังเป็น exponential และไม่เหมาะกับปัญหาที่มีการคำนวณซ้ำมาก (overlapping subproblems)

เทียบกับ DP: DP เหมาะกับปัญหาที่มี overlapping subproblems และ optimal substructure เช่น Fibonacci, Knapsack ส่วน Backtracking เหมาะกับ constraint satisfaction เช่น N-Queens, Sudoku

6. ออกแบบ Backtracking สำหรับ Sudoku 4×4 (โจทย์ ไม่มีเฉลยในหนังสือ)

หนังสือไม่ได้เฉลยข้อนี้ ตัวอย่างโค้ดด้านล่างเป็นแนวทางที่เขียนเพิ่มตามหลักการเดียวกับ N-Queens

def is_valid(g, r, c, v):
    for i in range(4):
        if g[r][i] == v or g[i][c] == v:      # แถว / คอลัมน์
            return False
    br, bc = (r // 2) * 2, (c // 2) * 2       # บล็อก 2x2
    for i in range(br, br + 2):
        for j in range(bc, bc + 2):
            if g[i][j] == v:
                return False
    return True

def solve(g):
    for r in range(4):
        for c in range(4):
            if g[r][c] == 0:                  # ช่องว่าง
                for v in range(1, 5):
                    if is_valid(g, r, c, v):
                        g[r][c] = v
                        if solve(g):
                            return True
                        g[r][c] = 0           # backtrack
                return False                  # ไม่มีเลขใดวางได้
    return True                               # เติมครบแล้ว

8.1หลักการทำงานของ Recursion

Base Case

เงื่อนไขหยุดการเรียกซ้ำ เมื่อปัญหาเล็กพอจะแก้ได้ทันที ถ้าไม่มีจะเกิด infinite recursion และ Stack Overflow

Recursive Case

ส่วนที่ฟังก์ชันเรียกตัวเองด้วยปัญหาย่อยที่เล็กลง จนถึง Base Case

โปรแกรม 8.1 · Factorial
def factorial(n):
    if n == 0:                     # Base Case: หยุดเมื่อ n = 0
        return 1
    else:
        return n * factorial(n-1)  # Recursive Case: ลด n ลง 1

ทุกครั้งที่เรียกฟังก์ชันจะเกิด Stack Frame ใหม่เก็บตัวแปรและตำแหน่งที่ต้องกลับไปทำต่อ การทำงานแบ่งเป็นช่วงลงลึก (calling phase) จนถึง Base Case แล้วช่วงย้อนกลับขึ้น (returning phase) ส่งค่าคืนทีละชั้น

factorial(3)
factorial(3)
→ 3 * factorial(2)
→ 3 * (2 * factorial(1))
→ 3 * (2 * (1 * factorial(0)))
→ 3 * (2 * (1 * 1))

Algorithm RecursiveFunction(parameters):

โปรแกรมคำนวณ Fibonacci ด้วยการเรียกซ้ำ
def fibonacci(n):
    if n <= 1:                                  # Base Case
        return n
    else:                                        # Recursive Case
        return fibonacci(n-1) + fibonacci(n-2)

เวลา: O(2ⁿ)

8.3Tower of Hanoi

มีเสา 3 ต้น (A, B, C) และดิสก์ n แผ่นซ้อนบนเสา A โดยแผ่นใหญ่สุดอยู่ล่าง ต้องย้ายทั้งหมดไปเสา C ตามกฎ: ย้ายได้ครั้งละ 1 แผ่น ห้ามวางแผ่นใหญ่ทับแผ่นเล็ก และใช้เสา B เป็นเสาช่วยได้

  1. ย้ายแผ่น n−1 แผ่นจาก A ไป B (ใช้ C เป็นเสาช่วย)
  2. ย้ายแผ่นใหญ่สุด (แผ่นที่ n) จาก A ไป C
  3. ย้ายแผ่น n−1 แผ่นจาก B ไป C (ใช้ A เป็นเสาช่วย)

T(1) = 1 และ T(n) = 2T(n−1) + 1 เมื่อ n > 1 ขยายสมการได้ T(n) = 2ⁿ − 1 จำนวนครั้งที่ต้องย้ายทั้งหมด

ลองเปลี่ยนจำนวนแผ่น

จำนวนครั้งที่ย้าย 2ⁿ − 1 = 7
    โค้ด Tower of Hanoi
    def hanoi(n, source, target, auxiliary):
    if n == 1:                  # Base Case: แผ่นเดียว ย้ายได้ทันที
        print(f"Move disk 1 from {source} to {target}")
    else:
        # Step 1: ย้าย n-1 แผ่น จากต้นทางไปเสาช่วย
        hanoi(n-1, source, auxiliary, target)
        # Step 2: ย้ายแผ่นใหญ่สุดจากต้นทางไปเสาปลายทาง
        print(f"Move disk {n} from {source} to {target}")
        # Step 3: ย้าย n-1 แผ่น จากเสาช่วยไปเสาปลายทาง
        hanoi(n-1, auxiliary, target, source)

    • Tail Recursion ประหยัดหน่วยความจำและแปลงเป็นลูปได้ง่าย
